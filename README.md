教务管理系统

基于 C# / WPF 的桌面端教务管理系统，支持管理员、教师、学生三种角色，覆盖学籍、课程、选课、排课、考试、成绩等教务业务

功能模块：

管理员端：学生档案、学生管理、教师管理、课程池、开课管理、排课、选课管理、考试管理、成绩发布、申请审批、公告管理、操作日志、数据库管理

教师端：个人信息、个人课表、成绩录入、成绩导出、监考安排、申请提交

学生端：个人信息、选课、我的选课、退课、个人课表、考试安排、缓考申请、免修申请、重修申请、成绩查询、课程信息、消息通知


技术栈： 
C# / .NET 8.0 + WPF 桌面客户端 + MySQL 8.0 数据库，
数据访问用 MySql.Data 直连，界面基于 MaterialDesign 组件库。

架构： 
两层 C/S。客户端（WPF）负责界面和业务处理，数据访问统一封装在 DbConnect；
服务端只有 MySQL，客户端通过 3306 端口直连，无中间服务器。
