教务管理系统
基于 C# / WPF 的桌面端教务管理系统，支持管理员、教师、学生三种角色，覆盖学籍、课程、选课、排课、考试、成绩等教务业务。
功能模块：
管理员端：学生档案、学生管理、教师管理、课程池、开课管理、排课、选课管理、考试管理、成绩发布、申请审批、公告管理、操作日志、服务器设置
教师端：个人信息、个人课表、成绩录入、成绩导出、监考安排、申请提交
学生端：个人信息、选课、我的选课、退课、个人课表、考试安排、缓考申请、免修申请、重修申请、成绩查询、课程信息、消息通知
